# HR Employee Attrition Analysis – Looker Studio

## Project Overview
This project focuses on analyzing employee attrition and workforce trends using Looker Studio. It aims to understand employee turnover patterns, explore workforce characteristics and present HR metrics through interactive dashboards.

## Project Objectives
- Analyze employee attrition patterns.
- Understand workforce demographics.
- Explore employee job roles and departmental trends.
- Identify key employee attrition indicators.
- Monitor HR performance metrics.
- Present insights through interactive dashboards.

## Tools & Technologies

- KPI Reporting
- Interactive Dashboards

## Key Analysis Areas
